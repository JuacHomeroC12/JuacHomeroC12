# Contribuir / Contributing

## 🇪🇸 Español

¡Gracias por tu interés! Este es un repositorio de perfil personal, pero las sugerencias son bienvenidas.

1. Abre un *issue* describiendo la mejora o el error (por ejemplo, un enlace roto o una errata).
2. Si quieres proponer un cambio, haz un *fork* y crea una rama: `git checkout -b fix/descripcion-corta`.
3. Usa mensajes de commit claros, preferiblemente con [Conventional Commits](https://www.conventionalcommits.org/es/) (`docs: corrige enlace de LinkedIn`).
4. Abre un *Pull Request* explicando qué cambia y por qué.

## 🇬🇧 English

Thanks for your interest! This is a personal profile repository, but suggestions are welcome.

1. Open an issue describing the improvement or bug (e.g. a broken link or typo).
2. To propose a change, fork the repo and create a branch: `git checkout -b fix/short-description`.
3. Write clear commit messages, preferably following [Conventional Commits](https://www.conventionalcommits.org/) (`docs: fix LinkedIn link`).
4. Open a Pull Request explaining what changes and why.
